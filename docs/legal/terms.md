# Skimlight 利用規約

施行日：2026年10月〇日（公開の日に記入）
運営：waiteu（個人事業主。以下「当方」）　お問い合わせ：contact@waiteu.dev

## 第1条（このサービスと、この規約の適用）
1. Skimlight（以下「本サービス」）は、公開されている募集要項などの文章を読み取り、締切・必須・数量・禁止・食い違いにあたる文に印を付けて表示する Web サービスです。URL を入力するほか、PDF を開く・文章を貼り付ける・ブックマークレット（ブラウザのお気に入りに登録して、開いているページの上で動かす小さな仕組み）を使う、の方法でも読み取れます。アカウントの登録はありません。
2. 本サービスを利用した時点で、この規約が適用されます。

## 第2条（判定しないこと）
1. 本サービスは、原文の該当箇所を示すだけです。応募の条件を満たすかどうかは判定しません。
2. 結果は、締切などの項目ごとに「引用あり」「引用なし」「要確認」の3つで示します（ブックマークレットの重ね表示では、印だけを付けます）。「引用あり」は関連する文があるという意味です。「引用なし」は、読み取った文章に関連する文が見つからなかったという意味で、条件が無いという意味ではありません。「要確認」は、関連する文に例外・食い違い・時刻の欠けがあるという意味です。
3. 最終的な判断は、原文と主催者の案内に基づいて、利用者ご本人が行ってください。

## 第3条（保証しないこと）
当方は、次のことを保証しません。
1. 印を付けた文が、関連する文のすべてであること（拾い漏れはありえます）。
2. 読み込んでから文字が表示されるページ、ログインが必要なページ、転送されるページ、画像だけの PDF の本文を読み取れること（ページを取得できなかった時は、多くの場合、別の読み方を画面で案内します）。
3. https で始まらないページ、大きすぎるページや PDF、PDF を指す URL を読み取れること。ページは約1MB、PDF は20MB を超えると読み取りません。PDF は最初の80ページ、文章は約20万字までを読み取ります。PDF は、URL ではなくファイルを開いて読み取ってください。
4. 「食い違い」の印が、本当に食い違っていること（同じ語の近くにある日付を機械的に比べています）。
5. 表示した後に、元のページが更新されていないこと。
6. 本サービスが中断せずに利用できること。

## 第4条（禁止事項）
次の使い方はしないでください。
1. 他のサイトに過大な負荷をかける使い方（自動化された手段による大量の取得を含みます）。
2. 公開されていないページや、取得が禁じられているページを読み取らせること。
3. 法令や、元のページの利用条件に反する使い方。
4. 本サービスの仕組み（回数の制限など）を不正に回避しようとすること。

## 第5条（元の文章の権利）
表示する原文の著作権は、元のページや文書の権利者にあります。本サービスは原文を保存しません。表示した原文を他の場所で使う時は、元の利用条件に従ってください。

## 第6条（料金）
本サービスは無料で、広告はありません。将来変更する場合は、何が無料のまま残るかを、事前に当方の Web サイト（https://waiteu.dev/）で告知します。

## 第7条（変更・終了）
本サービスを変更または終了するときは、事前に当方の Web サイト（https://waiteu.dev/）で告知します。ただし、障害や本サービスを置いているサービス（配信基盤）の停止による一時的な中断と、配信基盤そのものが終わったことによる終了は、事後に告知します。料金の変更（第6条）には、この例外を当てはめません。

## 第8条（規約の変更）
当方は、民法548条の4に基づき、この規約を変更することがあります。変更するときは、変更後の内容と、効力が生じる日を、相当の期間をおいて、その日より前にこのページに掲載します。

## 第9条（使っているソフトウェア）
本サービスは、PDF を読むために pdf.js（Apache License 2.0）を使っています。ライセンスの全文は〔/pdfjs/LICENSE へのリンク〕に掲載しています。PDF の文字の対応表（Adobe の CMap）のライセンスは〔/pdfjs/cmaps/LICENSE へのリンク〕に掲載しています。

## 第10条（お問い合わせ・準拠法）
お問い合わせは contact@waiteu.dev へお願いします。この規約は日本法に準拠します。
