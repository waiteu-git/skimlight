# Skimlight プライバシーポリシー

施行日：2026年10月〇日（公開の日に記入）
運営：waiteu（個人事業主。以下「当方」）　お問い合わせ：contact@waiteu.dev

## 1. 当方が残す情報
当方が残すのは、URL を受け付けるごとの短い記録（§3）だけです。アカウント、Cookie、アクセス解析、広告の識別子は使いません。このほか、次の2〜4のとおり、端末に保存するもの、サーバーが一時的に扱うもの、配信基盤に残りうる記録があります。

## 2. 端末に保存するもの
画面で選ぶ自分の立場（学生か社会人か・1人かチームか・成人か未成年か・国内に住んでいるか）は、立場を選ぶと、このブラウザの中（localStorage）に保存されます。「選び直す」で消えます。ブラウザのサイトデータを消しても消えます。立場の選択はサーバーへ送りません。URL にも含めません。

## 3. 読み取る文章と、サーバーが一時的に扱うもの
- PDF・貼り付けた文章：ブラウザの中だけで読み取り、サーバーへ送りません。
- ブックマークレット：押すと、このサイトからマーカーの部品を読み込みます（開いているページによっては、このサイトの画面を開きます）。読み取った文章は、開いているページの上か、このサイトの画面の中だけで扱い、サーバーへは送りません。部品を読み込む時の通信には、開いていたページのアドレスを付けません。このサイトの画面を開く時の通信には、開いていたページのアドレスが付くことがあり、§4 の記録に残ることがあります（多くはドメインだけですが、そのページの設定によってはアドレス全体です）。
- 入力された URL：そのページを1回取得するためだけに使い、保存しません。当方の記録に残るのは、結果の種類と、取得したページの大きさだけです。URL も、URL から作った記号も残しません。取得しなかった時（受け付けられない URL だった時など）も、同じ形の記録が残ります。この記録は §4 の配信基盤のログに置かれ、保存期間は配信基盤によります。
- IP アドレス：取得の回数を制限するためだけに、サーバーのメモリに置きます。最後に使ってから約1分を過ぎると、30秒ごとの掃除で消えます。記録には残しません。

## 4. 配信基盤
本サービスは、GMO ペパボ株式会社の「ロリポップ！デプロイナウ」（このサイトを置いているサービス。以下「配信基盤」）で配信しています。配信基盤には、IP アドレスを含むアクセスの記録が残ることがあります。その保存期間は公表されておらず、当方の設定では止められません。

## 5. 外部への通信
- URL を入力した時、本サービスのサーバーがそのページを取得します。取得先のサイトに見えるのは本サービスのサーバーで、利用者の IP アドレスではありません。
- PDF を読む部品（pdf.js）は、このサイトから配ります。外部の配信サービスへは通信しません。

このポリシーを変更するときは、変更後の内容と、効力が生じる日を、その日より前にこのページに掲載します。
